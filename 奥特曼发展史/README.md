# 奥特曼宇宙编年史 · ULTRAMAN UNIVERSE ARCHIVE

一个以「奥特曼宇宙数字博物馆」为主题的单文件交互式网站。以深空黑、银色、金色与红蓝为视觉基调，将**现实世界的系列发展史**与**作品内部的虚构宇宙史**严格分开，并提供作品、战士、事件、文明、战役与关联网络六个核心档案模块。

> 打开方式：双击 `index.html` 即可。无需后端、无需联网，所有样式、脚本与角色视觉均内嵌在文件中。

---

## 目录

| 路径 | 说明 |
| --- | --- |
| `index.html` | **最终交付文件**（约 2.1 MB，单文件自包含） |
| `dev.html` | 开发入口，外链 `src/` 下的样式与脚本 |
| `src/css/` | 样式分层：`base` / `layout` / `sections` / `photos` / `overlay` |
| `src/js/data.works.js` | 54 部作品档案（现实发行史） |
| `src/js/data.heroes.js` | 38 位奥特战士档案 |
| `src/js/data.events.js` | 31 条虚构宇宙事件（五纪元） |
| `src/js/data.factions.js` | 16 个文明与势力 |
| `src/js/data.battles.js` | 18 场经典战役 |
| `src/js/images.js` | 角色视觉的 WebP Data URI（构建时生成） |
| `src/js/art.js` | 原创 SVG 绘像 / 徽记生成器（图片缺失时的回退方案） |
| `src/js/app.*.js` | 应用逻辑：索引、渲染、弹窗、检索、收藏 |
| `assets/processed/` | 压缩后的角色视觉源文件（720px 高 WebP） |
| `tools/` | 构建、图片处理、无头浏览器 QA 与截图脚本 |
| `qa/` | 各页面截图与 `report.json` 验收记录 |

## 构建

```powershell
node tools/build.mjs   # 将 dev.html + src/* 内联为 index.html
node tools/qa.mjs      # 无头 Chrome 冒烟测试与截图（可选）
```

## 内容口径

- **现实发展史**只记录日本首播 / 首映年份与制作背景；日期以官方作品页与公开年表为准，不确定处只写年份。
- **虚构宇宙史**按 M78 主宇宙、TDG 宇宙、盖亚地球、新生代平行世界与独立作品分开记录，不强行拼成一条绝对时间线。
- 缺少官方依据的年代写作「年代未明确」，并标注「官方设定 / 作品描述」；不虚构身高体重、战斗力或未播出的项目。
- 收录至 2026 年 10 月：包含 2025 年《奥美迦奥特曼》与 2026 年 60 周年作《提欧奥特曼》（播出中，中文译名暂用）。

## 图像与版权

- 奥特战士全身视觉来自圆谷制作官方角色页面（m-78.jp），已下载并压缩为本地 WebP，仅用于本非商业粉丝档案。
- 作品海报版式、战役版画、势力徽记、星球 / 星图与界面图形为本站原创 SVG / CSS。
- 「奥特曼」系列及相关名称、角色形象的著作权归圆谷制作株式会社所有。本站为非官方粉丝项目，与圆谷制作无隶属关系。
