    实时输入台

    LOCAL TOKEN TRACE · NO API

    输入一句话，观察它如何被分词、变成向量、计算注意力，并走完生成循环。为了保持离线，本页不会调用真实模型；回答是预置演示文案，分词与注意力数值由本地计算。

    ABOUT · 关于

    这是一间原理演示实验室，不是模型监控台

    页面用 Three.js 搭了一条 13 站的推理流水线：从用户输入到 token 返回。可自动播放，也可以点击任意站台、拆开 Transformer、拖拽旋转场景，或在输入台里用任意文本触发一次模拟推理。

    演示边界

    • 3D 粒子、矩阵与耗时均为原理示意，不是真实张量。
    • Token 切分为近似演示，不同模型词表不同。
    • 示例回答为预置文案，本项目不连接任何 API。
    • 注意力矩阵与采样由本地小规模数值真实计算。

    操作

    • 拖拽旋转 · 滚轮缩放 · 右键平移
    • 点击站台或编号聚焦；点击 Transformer 拆解
    • 底部播放 / 上一步 / 下一步 / 速度
    • Esc 关闭面板；⌘/Ctrl + K 打开知识库

    内容口径

    以主流 decoder-only 模型为例，同时区分 Encoder-only 与 Encoder-Decoder；区分训练与推理、logits 与概率、Tokenization 与 Embedding、KV Cache 与对话历史。

    技术

    Three.js r147 · OrbitControls · UnrealBloomPass · GSAP · 原生 ES6。全部依赖已内联，离线可开，无 CDN、无网络字体、无统计。
