# 项目名称：Supercar 3D Experience —— 3A 级超跑数字展厅

## 一、项目愿景

开发一个基于 HTML5 + CSS3 + JavaScript + Three.js 的高品质 3D 超级跑车展示平台。

项目目标是打造一个接近 3A 大型赛车游戏汽车展示界面的沉浸式体验。

用户可以在网站中自由欣赏世界知名跑车，包括兰博基尼、法拉利、日产 GT-R、迈凯伦、保时捷、布加迪、科尼赛克等。

用户不仅可以从外部 360° 观察车辆，还可以打开车门、进入驾驶舱、观察方向盘、中控台、仪表盘、座椅等内饰细节。

同时支持自由调整车身颜色、轮毂、卡钳、内饰配色等配置，实时看到 3D 模型变化。

**核心要求：视觉品质必须接近 3A 赛车游戏的汽车展示画面，而不是普通 Three.js 教学示例。**

## 四、3D 汽车展示系统

这是整个项目的核心。

### 1. 360° 全景查看

用户可以通过鼠标自由操作车辆：

- 左右旋转车辆。
- 上下调整观察角度。
- 鼠标滚轮缩放。
- 查看车头、车尾、侧面、顶部和底盘。
- 双击车辆可以切换至重点观察模式。
- 一键恢复默认观察角度。

要求：
- 车辆旋转必须平滑。
- 摄像机移动不能突然跳跃。
- 不允许出现镜头穿模。
- 支持多个预设观察角度。

预设视角：
- Front：正前方
- Rear：正后方
- Side：侧面
- Front 45°：前方 45°
- Rear 45°：后方 45°
- Top：顶部
- Interior：内饰

### 2. 车身零件交互

支持点击车辆上的特定零件，查看对应信息。

重点部件：

- 前保险杠
- 前唇
- 引擎盖
- 车顶
- 车门
- 后视镜
- 前大灯
- 尾灯
- 进气口
- 后扰流板
- 排气管
- 轮毂
- 轮胎
- 刹车卡钳

鼠标悬停时显示部件名称。

点击后镜头平滑移动到对应位置，并展示部件介绍。

### 3. 车辆部件拆解

增加 Exploded View 模式。

用户点击「车辆拆解」，车辆的部分零件沿预设方向缓慢分离。

展示：

- 刹车系统
- 轮毂

可以拖动拆解进度，控制零件分离程度。

如果没有完整机械模型，则优先实现外观零件拆解，不要用虚假的机械结构冒充真实结构。

## 十一、3D 模型资源要求

这是项目成败最关键的部分。

必须优先寻找高质量、具有真实内饰结构的汽车 3D 模型。

模型资源优先级：

1. 官方授权模型。
2. 购买的高质量汽车 GLB / GLTF 模型。
3. Sketchfab 等平台上具有明确授权的模型。
4. 其他具有合法使用许可的模型资源。
5. 仅在无法获得模型时使用程序化模型作为临时占位。

不要直接使用低面数、卡通化、玩具感的模型。

不要使用一个通用跑车模型，通过更换车身颜色冒充不同品牌。

每辆车应该具有独立的模型资源和对应配置文件。

如果模型资源暂时无法获取：
- 先搭建完整系统。
- 设计模型加载接口。
- 使用高质量临时模型。
- 标记模型为占位资产。
- 保留后续替换真实模型的能力。

不要为了追求快速完成而牺牲模型真实性。

## 十二、性能优化

目标是达到流畅的高品质实时 3D 展示。

要求：
- 根据设备能力自动调整渲染质量。
- 支持高、中、低三档画质。
- 车辆模型按需加载。
- 使用 Draco 压缩。
- 纹理使用 KTX2。
- 使用 InstancedMesh 优化重复对象。
- 适当使用 LOD。
- 合理管理显存。
- 切换车辆时释放不再使用的资源。
- 避免不必要的实时阴影计算。
- 优化移动端性能。

桌面端优先保证画质，移动端优先保证流畅。

## 追加需求 v2（2026-11-05）：可行性收敛 —— 从「3A 三车」改成「单车全功能切片」

> 本节是对上面 v1 的**修订与取代**。冲突处一律以本节为准；本节没有提到的条目，v1 照旧执行。

### 一、裁定与依据

v1 的「27 款车型 + 至少 3 辆真实车型 + 3A 画质」在本仓库三条硬规矩（零外部请求 / 单文件 < 10 MB / 不虚构）下**无法同时成立**。依据是实测，不是估计：

| 实测项 | 结果 |
| --- | --- |
| 可自动化获取的高质量真车 GLB | 实际只找到 1 个：three.js 官方 `ferrari.glb`（Ferrari 458，随仓库 MIT） |
| Sketchfab 下载接口 | 匿名请求返回 **401**，必须登录授权；多为 CC-BY-NC，体积 30–80 MB |
| 该模型体量 | 358,788 面 / 337,068 顶点 / 51 mesh / 17 材质 / **0 张贴图 / 0 段动画** |
| 钣金分件 | 整个车身是**一片** `body`（80,566 面），无独立车门、引擎盖、保险杠、尾翼、前唇 |
| 可独立操作的节点 | 4 个轮组（wheel / rim / tire / brake / centre / nuts）+ 方向盘组（7 节点） |
| `file://` 实测 | blob Worker ✅ / `fetch('data:…')` ✅ / ES `import` ❌（被 CORS 挡） |

因此本期范围定为 **A 方案：一辆真车 + 一套做满的展厅系统 + 可替换的模型接口**。

### 二、数量口径变更

| v1 要求 | v2 口径 |
| --- | --- |
| 8 品牌 27 款车型 | **1 辆**：Ferrari 458（three.js 示例模型） |
| 第一阶段 3 辆完整展示 | 1 辆完整展示 + 配置驱动的模型加载接口（换 GLB 即扩展） |
| 车型切换栏 | 保留 UI 位：1 个真实条目 + 1 个「接入你自己的模型」说明项 |

命名纪律：模型是 458，UI 上就写 **Ferrari 458**。若无法确认具体子型号（Italia / Speciale），**不许靠猜补后缀**。

### 四、本期交付面

**展厅与渲染**

- 360° 环绕、7 个预设视角（Front / Rear / Side / Front 45° / Rear 45° / Top / Interior）、滚轮对数缩放、双击推近、一键复位。
- 程序化环境（**不用 HDRI 文件**）：自建最小场景 + `PMREMGenerator.fromScene` 生成 5 套 IBL —— Luxury Studio / Modern Garage / Night City / Mountain Road / Racing Track；切换时环境贴图与灯光同步换。
- 后期：ACES Filmic 色调映射 + UnrealBloom（阈值随场景变）+ SMAA；接触阴影用官方 `ferrari_ao.png`（21 KB 烘焙 AO，可选）或屏幕空间软阴影。
- 程序化材质 —— **模型零贴图，这是本期技术核心**：
  - 车漆 5 档：金属漆 / 珠光漆 / 哑光 / 高亮清漆 / 碳纤维外观。清漆用 `MeshPhysicalMaterial.clearcoat`；橘皮纹用运行时生成的噪声法线贴图（`CanvasTexture`，种子固定，保证可复现）。
  - 碳纤维：4×4 斜纹编织，解析式 shader 或运行时 Canvas 生成，**不引入贴图文件**。
  - 皮革 / Alcantara / 地毯：颗粒法线 + 各向异性近似。
  - 玻璃：`transmission` + `ior 1.5`；低画质档退回半透明，避免 transmission 的性能代价。
- 灯光：DRL / 近光 / 远光 / 尾灯 / 刹车灯 / 转向灯 / 双闪。靠 emissive + 灯罩节点（`lights` / `lights_red` / `leds`）实现，配 2 个真实光源打地面投影。

**配置**

- 车身色：12 个预设 + HEX/RGB 自定义；材质档 5 种。
- 卡钳色：红 / 黄 / 蓝 / 黑 / 银。**必须克隆 `brake` 节点的材质**，否则会连带轮辋一起变色。
- 轮辋色、内饰配色（Leather / Interior_dark / Carpet 三组）、碳纤维饰板开关。
- 「恢复原厂配置」。

**内饰**

- 方向盘组独立，可随视角转动；内饰换色。
- 仪表盘与中控屏用 Canvas 绘制后贴到自建平面，**UI 上必须标注「屏幕为程序化补建」**。
- 第一人称坐姿相机（FOV 65、眼高约 1.1 m），`Esc` 退回外观。

**环境音**

- WebAudio 程序化引擎声（V8 分谐波 + 随转速变化的滤波），默认静音，需用户点击才发声。

### 五、技术栈修订

| v1 | v2 | 原因 |
| --- | --- | --- |
| CDN 引入 Three.js / GSAP | 全部 vendor 进仓库，构建时内联 | 零外部请求 |
| KTX2Loader | **去掉** | 没有贴图文件 |
| RGBELoader / HDRI 素材 | **去掉**，改 PMREM 程序化 | 没有外部环境贴图 |
| DRACOLoader 默认按路径加载解码器 | **保留 + 覆写 `_loadLibrary`** | `file://` 下按路径取 wasm 会失败；覆写后直接返回内联的 wrapper 文本与 wasm 字节（无头 Chrome 已验证 worker 可用） |
| `<script type="module">` 直接引 src | **构建期 bundle 成单文件** | `file://` 下 `import` 被 CORS 挡 |
| GSAP | 可选；用也只做相机与 UI 缓动，其余交给 CSS | 省 70 KB |

构建工具二选一，**默认 (a)**：

- (a) `esbuild` 作 `devDependencies`（`node_modules/` 已在 `.gitignore`）：稳定、支持压缩。
- (b) 自研约 40 行内联器：把 `three.module.min.js` 末尾 `export {…}` 去掉，与 addons 顺序拼接，并删掉 addons 里的 `import … from 'three'`。零依赖，但脆。

体积预算（硬上限，构建脚本必须打印）：

| 组成 | 预算 |
| --- | --- |
| three + addons | ≤ 600 KB |
| Draco wrapper + wasm（base64） | ≤ 320 KB |
| `ferrari.glb`（base64） | ≤ 2.3 MB |
| 应用代码 + 样式 | ≤ 400 KB |
| **单文件合计** | **≤ 4 MB**（仓库红线 10 MB） |
